# PxWeb2 user guide

## Search for tables on start page

The search normally includes

-	Table titles
-	Contents variables, i.e. what is counted or measured
-	Variable headings (classifications)
- Groupings under variables
-	Value lists, for example numbers and names of municipalities or goods
-	Topics
  
The hit list is sorted by publication date. The most updated tables are placed at the top of the hit list.
The search does not include

-	Notes
- Contact information
  
We recommend combining searching with various filters on the page.

## Advanced search on start page
The search uses Lucene search syntax via PxWebApi 2.

### Search for multiple words
If you enter multiple words in the search field, you will get hits on tables that contain all of these words.

### Search by phrase
If you want to search for two or more words that are found right after each other in the table, put quotation marks before and after the phrase. 

### Search at the beginning of words
You can use the character * after the search term to get hits on all words that start with those letters. For example, searching for hydro* will return hits on "hydropower companies".

### Limit search to table title
If you want the search term to be found in the table title, put title: in front of the search term.

### Using logical operators
You can use the logical operators AND, OR or NOT. With OR you get a match if one of the terms matches. With NOT you can filter out words you don't want to include. The AND operator is implied if you type several words in succession.

### Hyphens and other special characters
It is possible to search for the characters . (period) and _ (underscore). 
However, as of today, you cannot search for the characters - (hyphen), + (plus), = (equals), / (slash) and ( ) (parentheses). Use quotation marks to search for texts containing such characters.

### Stop words
Small words that are very common are ignored, unless they are part of a phrase. Example: and, or, for, but, in, then, the, it, of, on, to.

### Proximity operator ~
Example "children adults" ~5 searches for "children" and "adults" less than 5 words apart.

### Search conditions that apply to multiple words
Use parentheses to group multiple search words under the same condition. Example: title:("retail trade" industry) searches for tables where both the phrase "retail trade" and the word "industry" appear in the title.

## Filtering
The start page shows the most recently updated tables, with filters on the left. Above the table list, you’ll see how many tables match your criteria. Up to 15 tables are shown on the first page. If there are more matches, a “Show more” button appears at the bottom of the list.

Filters include:

-	Topic
-	Year (from–to)
-	Time period (year, quarter, month, week)
-	Variable (e.g., region, age, industry)
-	Status (whether tables will be updated or not)

Each filter offers multiple options. Depending on your selections, the table list will change. You’ll always see how many tables match each filter option.

Selecting multiple topics can quickly become overwhelming. If you want to switch from one topic to another, remember to deselect the previous one, otherwise all selected topics are included (logical OR).

The **Variable filter** includes classification variables, but not contents variables (i.e., what is measured or counted). Selecting multiple variables will return tables that include all selected variables (logical AND). This helps narrow down the results quickly. The list is sorted by number of matches, and variables with no matches will disappear as you make new filter selections.

Above the result list, you’ll see the filters and search terms you’ve used. You can easily remove one or more selections to adjust your search. These filter choices are also reflected in the URL.

## Table page
The table page is divided into three sections. On the far left, there are five buttons:

-	Filter
-	Display
-	Edit
-	Save
-	Help
  
The table you see is generated by an algorithm and will change immediately when you select something under Filter. 

To view more of the table at once, click “Hide” and the arrows in the top right corner of the window.

## Algorithm for default table view
The purpose of the algorithm is to select two dimensions and display them for the user as stub and heading, respectively. Preferably, the two most characteristic dimensions should be shown so that the default view is as unique as possible. By dimension, we mean: contents variables, time, or another classification variable. 

The algorithm is created based on these criteria:

-	The table should be easy to understand.
-	The table should display a useful sample of the content.
-	We pick two dimensions and show them as columns and rows.
-	The dimensions should be the two most characteristic for this table.
-	The example table shouldn't be so big that it causes long response times.

The algorithm can be replaced by a saved query for each individual table. See [Default selection](https://www.pxtools.net/PxWebApi/documentation/configuration/#default-selection).
	
The algorithm works like this for a desktop:

1.  A matrix of values from the first and last classification variable is displayed, with the one that has the most values in the stub.  
2.  Mandatory classification variables are prioritized over optional ones.  
3.  The first contents variable and the most recent period are displayed at the top of the table header.  
4.   If the table has no classification variables, a matrix of contents variables and the 13 most recent periods is displayed. Fewer than 6 statistical variables are shown in the heading. 6 or more statistical variables are shown in the stub.  
5.   If the table only has one classification variable and one contents variable, a matrix of the 13 most recent periods is shown in the heading and the classification variable in the stub.  
6.   If the table only has one classification variable and several contents variables, a matrix of the contents variables and the classification variable, the one with the most values in the stub, is shown.   
7.   If a variable has a preferred grouping or set of values, this should be shown.   
8.   If a variable doesn't have a preferred grouping, the entire set of values should be shown.   
9.   If a variable doesn't have a preferred set of values, the first set of values should be shown.   
10.	  A limit of 1500 rows and 13 columns has been set.  

In mobile view the table always have only one column of figures. Variables with few values are sorted before variables with many values.

## Search in long value lists

-	You will get matches for words that start with the search term you enter.
-	If you also want to search inside words, put * before and after the search term.
-	If you want to search for several words in a row (a phrase), put quotation marks before and after the phrase.
-	The search term, in addition to letters and numbers, can contain characters such as . (period), _ (underscore), - (hyphen), + (plus), = (equals), / (slash) and ( ) (parentheses).
-	If the selection box (variable) contains many values, you will find a search field labeled “Search in list” at the top of the box.
-	If “Select all” is checked and you don’t need all the values, click “Select all” and you will see that the selections are cleared.
-	Search for what you want and check the items you want to include in the table.
-	Repeat the search until you have selected all the values you need.
-	When you search for a word, only the matching results will be displayed. Remove the search term if you want to search the entire list again.
-	A new search does not automatically remove previously selected values.
-	If you want to start over, click “Select all” twice, and all selections will be cleared.
-	The search field applies to the list of possible choices, not the table itself. If you want to search within the table, you can use Ctrl+F.

## Information
The “Information” button provides:

-	Notes (before footnotes) and symbol explanations
-	Definitions (links to variable definitions, classification standards and other metadata, if the px file contains meta-id’s for this.)
-	Table details (e.g., update date, unit of measurement, reference time)
-	Contact persons for the table

## Edit
- “Organise table automatically”: You can use this if you have made new selections in the table and want to rotate it for better readability.
- “Organise table manually”: You can arrange rows and columns just as you like, by drag and drop.
- “Rotate table”: Sometimes the table becomes easier to read if you switch rows and columns. You can rotate the table multiple times until you’re satisfied.

In mobile view, "rotate the table" is the only choice, since such tables always have only one column of figures.

### Algorithm for organise table automatically
1.	Place the dimension with the most values in the stub.
2.	Place the dimension with the second most values in the heading. If the product of the two dimensions with the second most values and the third most values (more than 1) is less than 13, place both in the heading, the one with more values at the bottom.
3.	Dimensions that only have one value are placed at the top of the heading. But if the table has more than 24 columns, they are placed first in the stub. If multiple dimensions have one value, place them in this order: Statistical variable (contents), time, classification.
4.	Other dimensions (>1 values) are placed in the stub. They are placed after dimensions with only one value and sorted by descending number of values.

## Save
You can save the finished table as a file. Available formats:

- Excel (.xlsx)
-	Semicolon-separated with header (.csv)
-	PC-Axis (.px)
-	JSON-stat2 (.json)
-	HTML (.html)
-	Parquet (.parquet)

## Link to updated table
You’ll get a unique link to your table, which we keep updated for you. You choose how new time periods are added:

-	Don’t add new time periods (table will only show your current selections)
-	Add new time periods (new periods will be added to your current selections)
-	Add new, time periods, but keep same number (new period added, oldest removed)
  
After making your selections, you’ll get a unique link based on your choices. If you make changes, a new link is created.

“Saved query” is not intended for automation. Instead, one should use the API for automation. 

## API Query
Use API query if you want to automatically download data to Excel, Power BI, or other systems. You can choose different formats. Read more about this in the PxWebApi user guide.
