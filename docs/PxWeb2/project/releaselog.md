# Release log

The list below highlights selected improvements and new features in PxWeb. For detailed release notes and the latest updates, follow the [PxWeb releases page on GitHub](https://github.com/PxTools/PxWeb2/releases).

## 2026

### PxWeb 2 
- Installation package for PxWeb 2 and PxWebApi 2
- Show version in the source code
- Links in global alert component
- Allow table ID to be hidden from table title in table card
- Enhance footer layout for table page
- Improve performance and layout at table page
- Show filter count for each filter category
- Enhanced variable box search (the search now matches the beginning of each word and includes expanded search capabilities)
- Improved format for footnotes
- Improved discoverability of variable groupings
- Access to MetaID metadata from the Definitions tab (Information panel)
- Open table card in new tab (right click)
- Display API queries directly in the user interface
- Extended table search (search across variables, values, and table content, with support for advanced search operators)
- Possibility for text and links in Help
- Button to improve table layout
- Saved query as alternative to algorithm (documentation)
- WCAG improvements

### PxWebApi 2

- Sort topics at levels 4 and 5 by sort code
- Creating saved queries now returns SavedQueryResponse instead of SavedQuery
